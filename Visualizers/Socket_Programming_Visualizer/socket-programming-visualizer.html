Socket Programming Visualizer

Two programs on two computers talk through sockets. Step through their calls one at a time, see what the operating system does with each one, and find out which calls make a program wait. Then write the same programs yourself on Linux, in C or Python.

→ Across: the client on the left, the server on the right; bytes travel between their sockets. ↓ Down: in each program, its calls above its socket.

What you will be able to do

    About this app. Socket Programming Visualizer works offline in any current browser. Its simulator follows what Linux does with TCP (Transmission Control Protocol) sockets, and every rule it shows was checked on a real Linux kernel. Buffers are drawn small so you can watch them fill; real ones hold tens to hundreds of kilobytes. Your progress is kept in this browser only.
