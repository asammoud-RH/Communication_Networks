Fragmentation Visualizer

Every link has a largest packet it can carry. When an IP (Internet Protocol) datagram meets a smaller link, IP cuts it into fragments, and only the destination puts them back together. See where the cuts fall, read every header field, and find the largest packet a path can carry with real ping commands.

About this app. Fragmentation Visualizer works offline in any current browser. It models IPv4 (IP version 4) with a 20-byte header and no options. A ping payload adds the 8-byte ICMP (Internet Control Message Protocol) header, and a UDP (User Datagram Protocol) payload adds the 8-byte UDP header. Routers fragment every fragment that is too big on its own, the way Linux does. Ping output follows Linux iputils ping and Windows ping: Linux ping sets DF by default and learns the path MTU; Windows ping sets DF only with -f. Linux never remembers a path MTU below 552 bytes, and it waits 30 seconds for missing fragments. Progress and badges are kept in this browser only.
