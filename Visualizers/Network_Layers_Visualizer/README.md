# Network Layers Visualizer

Compare the OSI (Open Systems Interconnection) model with the TCP/IP models, watch a message gain and lose its headers, and see what switches and routers rewrite.

- **Learn:** six short lessons with live figures.
- **Calculator:** Ethernet frame sizes and efficiency.
- **Challenge:** quizzes at three levels, with badges.

Open `network-layers-visualizer.html` in any browser. It works offline.
