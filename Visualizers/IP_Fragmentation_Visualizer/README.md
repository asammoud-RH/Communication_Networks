# Fragmentation Visualizer

See how IPv4 (Internet Protocol version 4) cuts a packet into fragments when a link's MTU (Maximum Transmission Unit) is too small.

## Modes

- **Learn:** six short lessons with animated figures.
- **Calculator:** any packet size over up to four links.
- **Challenge:** quiz rounds at three levels.

## How to use it

Download `fragmentation-visualizer.html` and open it in any browser. It works offline.
