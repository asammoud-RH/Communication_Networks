# Bandwidth and Latency Visualizer

An interactive app that shows how long data takes to cross a network: how bandwidth, distance, and waiting add up to latency, how many bits fill a link, and what rate a transfer really gets.

- See how long one bit lasts and how long it is on the wire.
- Split latency into queuing, transmit, and propagation delay.
- Watch a link fill with bits (the delay × bandwidth product) and find the window that keeps it full.
- Tell bandwidth from throughput, and follow one packet across a switch and a router.

## Modes

- **Learn:** six short lessons with animated figures.
- **Calculator:** one link or a path of up to four links.
- **Challenge:** quiz rounds at three levels.

## How to use it

Download `bandwidth-latency-visualizer.html` and open it in any browser. It works offline. Example link: `bandwidth-latency-visualizer.html?mode=learn&lesson=4`.
