# Fragmentation Visualizer

An interactive app that shows how IPv4 (Internet Protocol version 4) cuts a packet into fragments when a link's MTU (Maximum Transmission Unit) is too small, and how hosts avoid it.

- See where a datagram is cut and what each fragment's header says.
- Watch routers fragment it again on smaller links.
- Use the DF (Don't Fragment) bit and ping to find a path's MTU.

## Modes

- **Learn:** six short lessons with animated figures.
- **Calculator:** any size and up to four links.
- **Challenge:** quiz rounds at three levels.

## How to use it

Download `fragmentation-visualizer.html` and open it in any browser. It works offline. Example link: `fragmentation-visualizer.html?mode=learn&lesson=4`.
