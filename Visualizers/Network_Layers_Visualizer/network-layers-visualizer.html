Network Layers Visualizer

Every message you send is wrapped in layers, like an onion. There is more than one way to name those layers: the seven-layer OSI (Open Systems Interconnection) model, and the four-layer TCP/IP model the Internet uses. See both side by side, watch the headers go on and come off, and find out what every switch and router reads and rewrites.

    About this app

    Network Layers Visualizer works offline in any current browser. It compares the OSI (Open Systems Interconnection) seven-layer model with the four-layer TCP/IP model. Sizes follow Ethernet II: a 14-byte header, a 4-byte FCS (Frame Check Sequence), a 64-byte minimum frame, a 1500-byte MTU (Maximum Transmission Unit), an 8-byte preamble with its start delimiter, and a 12-byte gap between frames. Headers are IPv4 (Internet Protocol version 4) 20 bytes, IPv6 (version 6) 40 bytes, TCP (Transmission Control Protocol) 20 bytes, and UDP (User Datagram Protocol) 8 bytes, with no options unless you choose them. Wireshark on the sending host captures a frame before the network adapter pads it and adds the FCS. Progress, badges, and the animation speed are kept in this browser only.
