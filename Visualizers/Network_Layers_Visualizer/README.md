# Network Layers Visualizer

Compare the OSI (Open Systems Interconnection) model with the TCP/IP (Transmission Control Protocol/Internet Protocol) model, and watch a message gain and lose its headers.

## Modes

- **Learn:** six short lessons with live figures.
- **Calculator:** Ethernet frame sizes and efficiency.
- **Challenge:** quiz rounds at three levels.

## How to use it

Download `network-layers-visualizer.html` and open it in any browser. It works offline.
