# Bandwidth and Latency Visualizer

See how bandwidth, distance, and queues add up to latency, and how many bits fill a link.

## Modes

- **Learn:** six short lessons with animated figures.
- **Calculator:** one link or a path of up to four links.
- **Challenge:** quiz rounds at three levels.

## How to use it

Download `bandwidth-latency-visualizer.html` and open it in any browser. It works offline.
