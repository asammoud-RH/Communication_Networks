# Line Encoding Visualizer

Learn how line codes such as NRZ-L (Non-Return to Zero, Level), NRZI (Non-Return to Zero, Invert on ones), Manchester, and B8ZS (Bipolar with 8-Zeros Substitution) turn bits into signals a receiver can read, and why each one exists.

## Modes

- **Learn:** short lessons with live signals and tasks you can check, ending with every code step by step, side by side, and summed up on cards.
- **Calculator:** see any bits under any code.
- **Challenge:** fresh questions, badges, and a completion code.

## How to use it

Download `line-encoding-visualizer.html` and open it in any browser; it works offline.
