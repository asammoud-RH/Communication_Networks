# TCP Visualizer

Learn how TCP (Transmission Control Protocol) delivers every byte, once and in order, by stepping through connections on a timeline and on the TCP state diagram.

## Modes

- **Learn:** eight short lessons with step-by-step figures.
- **Calculator:** build any connection and see every segment.
- **Challenge:** quiz rounds at three levels.

## How to use it

Download `tcp-visualizer.html` and open it in any browser. It works offline.
